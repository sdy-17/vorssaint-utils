# 个人集成开发分支

基于 [vorssaint/vorssaint-utils](https://github.com/vorssaint/vorssaint-utils) 的个人开发 fork，保留上游代码、许可证与归属说明。本仓库发布的是开发源码，不代表上游官方发行版。

## 新增功能

- 显示器：已有 HiDPI 模式、分辨率与刷新率切换、主屏设置、RGB ICC 颜色配置切换，以及显示配置保存和恢复。
- 显示变更：先临时预览，确认后持久保存；超时撤回，并处理显示器断开和颜色配置恢复。
- 截图：F1 框选后直接原位标注，保留暗色冻结背景，显示紧凑工具栏；边线和八个控制点支持扩大、缩小范围，标注保持屏幕位置，支持撤销／重做。
- 截图性能：复用选区窗口与原生背景层，取消空窗口列表的同步提交，普通标注不主动运行 OCR；选择文字或文字马赛克按需识别。
- 截图隐私：移除应用切换器在启动和应用激活时自动抓取窗口缩略图的预热；主动打开切换器／Dock 预览时仍可按需捕获。主动录屏、窗口监看等功能不受此改动影响。
- 截图取消：顶部 Esc 提示可点击取消，退出时先隐藏再释放遮罩，原位编辑期间阻止重复截图会话。
- 待办：先在功能中心安装“待办”，再从菜单面板、快捷工具设置页或全局快捷键打开。默认 `⌃⌥⌘Y`（Control + Option + Command + Y），打开／再次唤起时聚焦输入框（若正在编辑则恢复该编辑草稿），输入后按 Return 保存并继续录入，Esc 关闭面板；普通关闭／重开会保留当前进程内未提交的新增草稿（不保证卸载功能或重启后保留）。双击待办标题或其右侧空白区域即可编辑并自动聚焦，Return 保存，编辑时 Esc 取消（不关闭面板），也保留“编辑”按钮；双击列表下方空白进入新增输入并保留已有新增草稿，Return 才真正保存（不插入空白任务）；支持完成／恢复、删除，以及全部／未完成／已完成筛选；在已完成筛选下新增成功会切到未完成。可在“设置 → 快捷工具 → 待办”或统一快捷键页修改／关闭快捷键；隐藏菜单入口不会关闭快捷键，卸载功能会注销快捷键。内容只保存在本机私有数据目录，不随设置备份导出；快捷键偏好随设置备份保存。不包含云同步、定时提醒或日历集成。

- 灵动岛待办：像草稿一样在岛内操作列表，不使用固定的集中编辑框。双击事项原行编辑，单击尾部空白聚焦底部新增草稿行，Return 才保存；保存失败保留输入。默认同时显示未完成和已完成，完成后留在原位并加勾／删除线；每条事项使用持久化的彩色圆圈。已完成行可手动归档，在“归档”视图恢复；归档不删除内容。可在“设置 → 快捷工具 → 待办”配置完成后自动归档天数，0 为从不自动归档，恢复后的事项重新计时。快捷键和菜单只在你主动打开时展开待办分区；收起时不显示待办摘要、数量或示例，也不加入紧凑活动选择器。草稿在当前进程跨收起／切页保留，重启不保留；独立窗口作为显式备用或灵动岛不可用时回退。沿用灵动岛分区隐藏／排序，不启用屏幕捕获、云同步或轮询；自动归档只用最近截止日期的一次性计时器。

显示器功能仅提供系统／驱动已有且通过检查的模式，不包含虚拟屏或镜像功能。截图性能的体感改善仍需要持续验证，不宣称零延迟。

要求 macOS 14+、Apple Silicon 和 Xcode Command Line Tools。沿用上游开发构建流程：

```sh
./build.sh --dev
./build/VorssaintDeveloper --selftest
./build.sh --test-suite=display-configuration --test-suite=settings --test-suite=screenshots
```
